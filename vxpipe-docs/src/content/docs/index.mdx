## Transport and pipeline, together

VxPipe gives a voice agent one runtime from the caller's first word to the
agent's response. Keep the audio path, model loop, tools, and handoffs in one
place instead of coordinating separate real-time systems.

<CardGrid>
  <Card title="Meet callers anywhere" icon="phone">
    Serve conversations in the browser or over the phone through a shared call
    engine.
  </Card>
  <Card title="Compose the full agent loop" icon="random">
    Connect streaming speech, model inference, tools, and audio output with
    clear, replaceable provider boundaries.
  </Card>
  <Card title="Keep control of the runtime" icon="server">
    Run VxPipe on your infrastructure and choose the services that fit your
    product.
  </Card>
  <Card title="Bring in the right person" icon="comment">
    Build transfers and human handoff into the same conversation flow as your
    agents.
  </Card>
</CardGrid>

## Quickstart

Run VxPipe locally with Docker.

<Steps>
1. **Run the container.**

   ```shell
   docker run --rm -p 4000:4000 \
     vxpipe/vxpipe
   ```

2. **Open VxPipe.**

   Visit [localhost:4000/start](http://localhost:4000/start).
</Steps>
