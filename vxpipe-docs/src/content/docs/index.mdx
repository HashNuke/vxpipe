## How it works

<div className="how-it-works">
<Steps>
1. **Connect your providers.**

   Add speech, model, and phone credentials for a tenant. VxPipe stores them encrypted in your
   database.

2. **Describe the call.**

   Write a call spec: the agents, their instructions and providers, their MCP tools, the call
   variables to collect, and who may transfer to whom. Each saved call spec is an immutable
   version.

3. **Take calls.**

   Callers join from a phone number or a web page. Follow each call live, then review its
   timeline and recording afterwards.
</Steps>
</div>

## Quickstart

<div className="section-lede">
  The Docker image is coming soon. Until then, run VxPipe from source. You need Elixir 1.19,
  PostgreSQL, Node.js 24, a Rust toolchain, and API keys for Gemini and Deepgram.
</div>

<Steps>
1. **Clone and install.**

   ```shell
   git clone https://github.com/HashNuke/vxpipe.git
   cd vxpipe
   mix deps.get
   mix assets.setup
   ```

2. **Create the database.**

   ```shell
   mix ecto.create
   mix ecto.migrate
   ```

3. **Add your provider keys and start VxPipe.**

   Set up a tenant with your Gemini and Deepgram keys by following the guide, then run:

   ```shell
   export VXPIPE_DEV_TENANT="TENANT_KEY"
   APP_HOST=localhost VXPIPE_DEV_TLS=http mix run --no-halt
   ```

4. **Talk to the sample agent.**

   Open [the voice console](http://localhost:4000/admin/samples/pipecat-console), select
   **Create room**, then **Connect**. Ask "What time is it?", then say "Transfer me to billing."
</Steps>

## FAQ

<div className="faq">
  <details>
    <summary>Is VxPipe ready for production?</summary>

    Not yet. VxPipe is pre-release and under active development, and we have not published
    load-test results. Progress is tracked in the open in the
    <a href="https://github.com/HashNuke/vxpipe/blob/main/docs/milestones/index.md">milestones</a>.

  </details>
  <details>
    <summary>Do I need to know Elixir?</summary>

    Not to build agents. Agents, providers, and tools are described in call specs, and tools
    connect over MCP, so they can be written in any language. Running VxPipe from source needs
    the Elixir toolchain today; a Docker image is planned.

  </details>
  <details>
    <summary>Where does my call data go?</summary>

    Call audio and text go to the phone, speech, and model providers you configure. Call history
    stays in your PostgreSQL, recordings go to your S3-compatible bucket, and provider keys are
    stored encrypted. VxPipe has no hosted service of its own.

  </details>
  <details>
    <summary>What does it cost?</summary>

    VxPipe is free and open source under the Apache 2.0 license. You pay your providers and your
    hosting costs directly.

  </details>
  <details>
    <summary>Can my agents call my own APIs?</summary>

    Yes. Put your APIs behind an MCP server and give agents access in the call spec. Elixir
    applications can also provide tools directly.

  </details>
</div>
