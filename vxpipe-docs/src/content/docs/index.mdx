## Quickstart

Run VxPipe locally with Docker.

<Steps>
1. **Run the container.**

   ```shell
   docker run --rm -p 4000:4000 \
     vxpipe/vxpipe
   ```

2. **Open VxPipe.**

   Visit [localhost:4000/start](http://localhost:4000/start).
</Steps>
