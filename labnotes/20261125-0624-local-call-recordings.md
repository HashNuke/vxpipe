# Local transfer-test recordings

The handset fixture disabled audio recording during the prior manual call and Telnyx returned no recordings for that time window. The test runner can retain the production room recorder's permitted full mix through a local ObjectStore adapter. Both the handset and unattended recovery-transfer lanes enable this writer. Each run gets a private directory under the checkout's existing ignored tmp/live-telephony path. Each call incarnation has an independent room.wav. A chunk updates its PCM and header before completion, so audio already received is playable if a test fails later. Sample offsets preserve internal gaps as silence. Carrier-generated audio after the local reception room closes can be present in a surviving machine endpoint's recording; a manual handset without its own capture has no such local endpoint.

A focused WAV layout and gap test failed before the local writer existed (seed 933853), then passed with the writer (seed 827817). The first live wiring check rejected admission when the writer and room pull limits were missing. The runner now supplies the same bounded limits used by the Console recording pipeline.

The unattended live call (seed 999596) passed in 31.2 seconds, with three retained 48 kHz mono WAV files of 2.78, 8.16 and 18.92 seconds. Each contained nonzero PCM. The longest file is the machine caller mix. After downsampling the caller mix and source assets to 2 kHz, five consecutive 0.5-second café-bossa windows matched at offsets 6.87, 7.37, 7.87, 8.37 and 8.87 seconds in the caller WAV (normalized waveform correlations 0.69–0.77). This supports audible wait music on the machine call. It cannot establish what played on the earlier handset call.

The final umbrella run with seed 293609 passed across all ten applications, including 683 Console tests. Formatting, warning-strict compilation, strict Credo, unused dependency checks, and Lean verification passed. An earlier run overlapped fixture edits and encountered a stale Console fixture and one WebRTC handoff failure; the ten focused WebRTC cases passed with the original seed before the full rerun.
