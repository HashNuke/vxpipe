# STS tool origin

- Scope: bind opted-in tool-call evidence to its accepted response context at the shared channel and capability. This is an origin-correlation checkpoint, not exact tool holds or root retirement.
- Observation: `tool_call` lacked `response_context`; the channel admitted contextless calls and the capability derived tool evidence from its current input epoch. A delayed old-origin call could therefore be forwarded under a new epoch.
- Red proof (Call Engine child, seed 0): `mix test test/vxpipe/call_engine/speech/sts_input_context_test.exs test/vxpipe/call_engine/capability/sts_capability_origins_test.exs --seed 0` returned 52 tests, 2 expected failures. The channel accepted a contextless opted-in call (`:ok` instead of invalid-event), while a context-bearing old call was rejected at `Event.build` (`:invalid_event` instead of reaching the origin check).
- Decision: `tool_call` accepts an optional opaque context at the generic event shape, but descriptor support requires it exactly for response-start opt-in and forbids it for legacy STS. Channel admission validates accepted/exactly staged contexts; the existing early-event queue withholds staged calls and fails a rejected first-use callback. A previously accepted A call survives a rejected staged B input. Capability admission compares the event's accepted fingerprint with its current authorization fingerprint before forwarding, and records the context with the pending tool. A stale A call after B becomes current fails the capability explicitly, avoiding a silent unanswerable provider tool obligation. This is a safety fence, not successful cross-origin continuation.
- Google adapter emits the interaction's bound context only in its opted-in profile; legacy output remains unchanged. Its response owner already creates the tool turn against that same context.
- Focused green (Call Engine child, seed 0): 89 tests, 0 failures across the context/channel/capability, fake Google session and legacy tool tests. Broader relevant group with event contract, Google controller, room tool lifecycle and identity: 212 tests, 0 failures. No hosted Google call was made.
- Independent native Codex Astra xhigh source review found no actionable issue in channel staging/rejection, capability old-origin checks, Google context emission or legacy behavior. Its separate focused run passed 86/0 before the last legacy and rejected-first-use cases were added. The later 89/0 and 212/0 local groups cover those additions. Review did not clear exact tool-origin retirement.
