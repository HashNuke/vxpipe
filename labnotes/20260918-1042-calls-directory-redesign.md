# Calls directory redesign

## Goal

Bring the Storybook Calls directory and its production API in line with the requested compact
columns, lifecycle vocabulary, searchable call-spec filter, local timestamps, and pagination.

## Progress and decisions

- Confirmed that persistence already pages with `created_at DESC, public_id DESC`; no ordering
  implementation change was necessary.
- Kept the rich `CallDirectorySummary` domain value because call-details authorization also uses it.
  Reduced only the directory JSON contract and introduced a separate frontend directory-item type.
- Mapped prepared/admitting/running to `ongoing`, and ended/failed to `ended`, at the Console
  presentation boundary.
- Removed archive completeness, duration, terminal reason, and start/end times from directory JSON
  and rows. The inspection endpoint remains unchanged.
- Replaced the native definition selector with a shadcn-style Radix Popover + cmdk combobox. Added
  direct `@radix-ui/react-popover` and `cmdk` dependencies.
- Changed Services hover timestamps from UTC serialization to the same browser-local formatter used
  by Calls.
- Made the primary populated story a working three-page example and kept filtered fixture results
  unpaginated.

## Red/green evidence

- Red: `AdminCallsEndpointTest` returned the old internal state and archive/inspection fields.
- Red: focused Vitest tests could not find the requested columns, searchable call-spec control,
  local timestamp title, or populated-story pagination; the old parser rejected `ongoing`.
- Green: focused endpoint test passes after the reduced JSON projection.
- Green: focused AdminApp, call-directory, parser, and Services tests pass after implementation.
- Green: 62 affected frontend tests pass together; TypeScript and ESLint pass.
- Green: Storybook production build passes.
- Green: umbrella formatting, warnings-as-errors compilation, strict Credo, and unused-dependency
  checks pass.

## Browser evidence

- Chrome, 1440×900: verified the compact columns, call-spec version badges, two state badges,
  local/relative times, and pagination in the populated story.
- Exercised search for `appointment`, selected Appointment reminders, and verified the two matching
  rows and URL-backed filter state.
- Chrome, 390×844: verified the bounded horizontal table, readable ID/spec columns, and working

- No browser console errors were reported.

  Chrome checks were completed with agent-browser instead.
