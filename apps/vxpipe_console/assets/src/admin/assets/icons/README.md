inventory. Each icon records its provenance and usage notes below.

- Source: Google's official full-color G mark:

- Status: official Google trademark asset. It is not an open-source work.
- Usage: use the unmodified resized asset to identify the integrated Google
  provider; do not imply endorsement or affiliation beyond the integration.
